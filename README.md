# 🪙 DX Coin - العملة الذهبية الرقمية

مشروع ويب تفاعلي لعملة DX Coin الرقمية مع تأثيرات نانو تكنولوجي متقدمة.

## ✨ المميزات

- تصميم عصري متجاوب
- تأثيرات بصرية متقدمة (نانو تكنولوجي)
- دعم اللغة العربية (اتجاه RTL)
- تفاعلات سلسة وتحسينات للأداء

## 🚀 طريقة التشغيل

1. قم بتنزيل الملفات
2. افتح `index.html` في المتصفح
3. أو ارفع الملفات إلى خادم ويب
